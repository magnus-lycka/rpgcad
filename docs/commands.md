## Menu

We have two distinct modes, Edit and Play, but we show the same, thin menu at the
top, but with different elements visible in edit and play

### Selection section

Only one button, but switching based on mode.

- Play button - Edit - ⇧E
- Stop Button - Play - ⇧E

### File Section
