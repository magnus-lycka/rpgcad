# Inspected Traveller component inventory

Inspected 2026-10-09 against Robert Pearce's **Starship Symbols**, released August 1, 2020, downloaded from [Eric Smith's mirror](https://ericbsmith.no-ip.org/zip/Geomorphs/PDF/Starship_Symbols.pdf). The 55-page PDF identifies Pearce Design Studio, LLC as copyright owner and displays CC BY-NC 4.0. Its introduction describes drawing aids rather than replacements for starship design under Traveller rules.

This inventory describes actual visible source content. Entries are identifiable **families**, not assertions that each family contains only one reusable asset. Page references use PDF page numbers, which match printed numbering through page 44. Page locations are stated from the reader's viewpoint; left/right refer to page halves. Open the linked PDF at the page and location to identify the drawing. Names below are descriptive catalog names, not invented technical functions for unlabelled shapes.

## Dimensions and behavior

Except the explicitly labelled cargo sizes below, **physical dimensions remain unverified** for these entries. Some room drawings have a visible square grid, but no unit calibration was established from the inspected Symbols pages. Do not turn visual proportions or raster bounds into claimed metre dimensions. The companion raster exports describe 300 pixels per **5-foot** square; using that convention for a specific asset requires verifying its export identity and scale. Five feet is 1.524 m and must not silently become RPGCAD's exact 1.5 m.

Source drawings establish appearance and, where labelled, intended type/direction. They do not establish RPGCAD sight blocking, interaction states, attachment rules or game statistics. In particular, **UP/DOWN describes vertical access, not whether a door is open or closed**. A ceiling hatch drawn dashed must not be mistaken for an open doorway. Rotations and mirrors need checking against text, controls, entry positions and directional markings.

## Using the inventory

Preserve the distinction between a sourced **appearance**, a verified **physical footprint**, and interactive **behavior**. An image can supply the first without the other two. Reusable variants should retain their source identifiers, even when several share a recognizable style. Entry selection should follow the Referee's intent; these references are a vocabulary for reuse, not permission for an agent to populate a plan speculatively.
